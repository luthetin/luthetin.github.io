GeoStructure Builder

构造地质学建模 · 单文件网页 / 离线可用 · 2026 年 · 已开源

这是给构造地质学做的一个地层建模与演示工具：在平面整数格上摆控制点、连成骨架面，程序把它渲染成光滑曲面；多个这样的面按沉积次序叠起来，就成了一个可以转着看的立体地层块——带厚度、带剖面、带露头带，还有一张实时的平面图。

起因很简单：用通用几何软件画三维地形时，稍微复杂一点的曲面就没法建模。于是干脆自己写一个——整个程序就是一个 HTML 文件，不联网、不装任何东西，双击就能用，也能放在手机上。

它在解决什么问题

  • 地形怎么摆进模型：控制点排在平面整数格上，连成正方形、每格加一条对角线分成两个三角形——这就是「骨架面」。拖动控制点改高度，骨架面被数学地渲染成光滑曲面。
  • 两种曲面：插值型（Catmull-Rom）严格穿过每个控制点，所见即所得；逼近型（三次 B 样条）被控制网拉着走，形状更柔顺。
  • 地层要有厚度：两个相邻交界面之间是一个地层实体（顶面 + 底面 + 四周侧壁），剖面因此是实心的，整个模型再接一块纯平地面封成方块。
  • 叠置反了怎么办：这是最费功夫的一条——「某处若有更年轻的界面压在下面，这张面在那一处就透明」。规则用连续的有符号场实现（不是逐顶点的开关），透明边界才能精确落在两个面的交线上，不会出现网格状的锯齿。

它长什么样

  • 表露面（露头带）：俯视地表，颜色按「地表正下方压着的那一层」一层一层地换。带与带的分界只可能是界面与地表的交线，而颜色边界是把跨带的格子沿交线切开得到的——精确、锐利，和画在那里的交线窄带重合。
  • 实时平面图：右边一张俯视小图，三种模式——彩色（颜色表示高度）、黑白（纯白底 + 黑线）、用层面自身颜色（和表露面一样的露头带色带）；交线默认只画露头迹线（与地表相交的那些）。
  • 等高线：画在最高次序的界面上，带地图式的数字标注（数字处线断开、数字沿线方向旋转），有一个「自动」按钮按起伏自适应选等高距。
  • 手机 / 平板：窄屏时两侧面板收成抽屉，单指拖动改高度、单指拖空白旋转、双指捏合缩放；触屏用「多选」「整体升降」两个开关代替 Shift 与空格。相机距离按屏幕宽高比自适应，竖屏也会自动拉远，模型不会溢出画面。
  • 存与取：可命名、保存/打开 JSON，自带一个内置预设（19 个交界面 / 18 个地层的柱状模型）。

技术

  • 零依赖：手写 WebGL（两个着色器程序、轨道相机、逐顶点属性），没有用任何图形库；曲面是张量积三次样条，等值线用 marching squares，界面与界面、界面与地表的交线都用「连续场 + 平移窄带」画成平滑细线。
  • 可验证：数学、规则、几何、交互都做了数值断言——用一个假的 WebGL 上下文和一个假的 DOM，把程序在 Node 里完整跑起来，逐点核对规则定义、三角形绕序、绘制顺序、存档往返等等，目前 195 项全部通过。
  • 踩过的坑也留着：README 里记着每一条「为什么这么做、之前错在哪」，包括几个只有真机才暴露的问题（比如测试里假 GL 的 createTexture() 返回 undefined，把一类资源刷新的 bug 完全遮住了）。
