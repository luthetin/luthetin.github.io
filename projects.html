探索台 · Explore Hub

个人工作台 · Cordis 插件 · 2026 年 · 前后端全自研 · 已开源

「探索台」是一个挂在 DeepSeek Harness 上的个人工作台插件：把「探索方向」「钱与时间」「目标计划」「日历日程」「API 钱包」收进同一个侧边栏，既能在浏览器里点，也能直接对 AI 说自然语言让它代劳。所有数据存在本地，自己完全掌控。

项目现已开源：github.com/luthetin/explore-hub

它能做什么

  • 方向管理：注册探索方向（如某个自媒体赛道），可冻结、归档，按方向记录投入的时间。
  • 双账本：记录支出 / 收入 / 转账，多账户 + 收支分类，流水可随时回溯；另有系统账户「api 钱包」直接对接 DeepSeek 余额。
  • 目标计划：目标（挂在方向下）→ 计划 → 子计划 三级结构，支持简称 / 全称 / 颜色，完成状态自动汇总进度条。
  • 周期计划：按周 / 按月重复的固定节奏（如每天晨读），设每日次数，支持逐日打卡。
  • 待办：轻量 checklist，随手记下要做的事。
  • 日历日程：年 / 月 / 周 / 日四种视图；计划可拖拽部署到某一天，设时间段（30 分钟粒度吸附），右键菜单改时间 / 简称 / 颜色 / 删除。
  • 概览页：今日时间与净额统计 + 今日计划清单，勾选完成即全视图同步（月视图绿点、周/日视图划线打勾）。
  • API 钱包：DeepSeek 实时余额 + 当月用量（请求数 / token / 花费），60 秒缓存。
  • AI 工具层：为 AI 注册 6 个工具（查状态、记账、转账、管理计划、看报表、查钱包），一句话即可操作整个工作台。

架构

  • 后端（Host）：Node.js 服务，`/explore/*` 路由处理方向 / 账户 / 分类 / 记账 / 转账 / 目标计划 / 周期计划 / 日历部署的增删改查；报表聚合（收支汇总、分类占比、方向投入、目标进度）前后端共用同一份实现。
  • 前端（Client）：浏览器侧边栏界面，五个页签（概览 / 方向 / 记账 / 日程 / 计划）+ 报表；自绘下拉、拖拽部署、时间轴拖拽、右键菜单全部原生 JS 实现。
  • 数据：本地 JSON 文件 + 追加式流水（JSONL），写入前自动备份（保留 50 份），路径可用环境变量覆盖。

技术栈
