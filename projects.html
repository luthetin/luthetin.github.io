探索台 · Explore Hub

个人工作台 · Cordis 插件 · 2026 年 · 前后端全自研

「探索台」是一个挂在 DeepSeek Harness 上的个人工作台插件。功能包括：方向管理、账目记录、目标计划、日程部署。数据存储于本地 JSON 文件，可直接读写。

功能

  • 后端：Node.js 服务，若干路由处理方向/账户/分类/记账/转账/目标计划/日历部署的增删改查，数据存本地 JSON 文件（`D:\探索计划表`）。
  • 前端：浏览器界面，五个页签：概览、方向、记账、日程、计划。日程有年/月/周/日四种视图，支持将计划拖拽到日历部署。
  • AI 工具层：为 AI 注册 6 个工具（查状态、记账、转账、管理计划、看报表、查 API 钱包），可通过自然语言操作工作台。
  • 测试：后端 50+ 条自动化测试，前端模拟 DOM 运行时测试。

技术栈

Node.jsCordis原生 JS无框架本地 JSON 存储自动化测试
