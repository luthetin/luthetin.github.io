# 视频背景放在这里

首屏（Hero）的视频层读的就是这个路径：

```
public/media/hero.mp4
```

把文件放进来、文件名保持 `hero.mp4`，重新构建（`npm run build`）即会自动播放。

在文件存在之前，首屏用 `public/hero.jpg` 做海报图，并叠一层实时 WebGL 帷幕
（`src/components/bits/DarkVeil.tsx`）与颗粒，所以现在看起来已经是"动态背景"，
不会出现空白。

## 建议规格

- 分辨率 1920×1080 或 2560×1440，竖屏另备一份可选
- 时长 6 到 12 秒，无缝循环，没有明显起止
- 码率控制在 2 到 4 Mbps（首屏体积别超过 3MB，否则首屏会慢）
- 无声（`muted` 已是默认，浏览器也要求静音才能自动播放）
- 画面偏暗、低饱和最贴合当前配色；亮部建议压到中间调，避免压过大标题

## 换成别的文件名

改 `src/sections/Hero.tsx` 里 `<video src="./media/hero.mp4">` 的路径即可。
